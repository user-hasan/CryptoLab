# CryptoLab — التثبيت والتشغيل دون اتصال بالإنترنت

## الحزمة الجاهزة

تم بناء مُثبّت Windows ذاتي الاكتفاء للنسخة `1.1.0`، مخصص لأجهزة Windows ذات معمارية `x64`.

اسم الملف عند بنائه محلياً:

```
CryptoLab Setup 1.1.0 win-x64.exe
```

تم رفع المثبت إلى GitHub ضمن إصدار مستقل يمكن الوصول إليه من خلال:

[صفحة إصدار CryptoLab 1.1.0 على GitHub](https://github.com/user-hasan/CryptoLab/releases/tag/v1.1.0)

ويمكن تنزيله مباشرة من الرابط التالي:

[تنزيل CryptoLab Setup 1.1.0 win-x64.exe](https://github.com/user-hasan/CryptoLab/releases/download/v1.1.0/CryptoLab.Setup.1.1.0.win-x64.exe)

> قد يظهر اسم الملف في GitHub بالشكل `CryptoLab.Setup.1.1.0.win-x64.exe` بسبب تطبيع المسافات في اسم الملف أثناء رفعه. وهو الملف نفسه.

يحتوي المثبت على ملفات التطبيق وبيئة تشغيل .NET اللازمة محلياً، ولذلك لا يحتاج المستخدم إلى تنزيل .NET أو الاتصال بالإنترنت بعد اكتمال التثبيت.

## طريقة التثبيت

نزّل ملف المثبت من رابط GitHub، ثم شغّله على جهاز Windows واتبع خطوات التثبيت. يمكن اختيار إنشاء اختصار في قائمة ابدأ وعلى سطح المكتب أثناء عملية التثبيت.

بعد اكتمال التثبيت، شغّل التطبيق من الاختصار الذي تم إنشاؤه أو من الملف التنفيذي `CryptoLab.exe` داخل مجلد التثبيت.

## التحقق من عدم الحاجة إلى الإنترنت

تتضمن حزمة التثبيت ملفات runtime المحلية، ومنها:

```
coreclr.dll
hostfxr.dll
hostpolicy.dll
```

إضافة إلى ملفات .NET Runtime الأخرى اللازمة لتشغيل التطبيق. وبناءً على ذلك، لا يُفترض أن يحتاج التطبيق إلى تنزيل مكونات إضافية من الإنترنت بعد التثبيت.

تم اختبار التثبيت بصمت في مجلد مؤقت، وانتهت العملية برمز الخروج `0`. كما تم التحقق من وجود ملفات التطبيق وتشغيل `CryptoLab.exe` بنجاح بعد التثبيت.

## التحقق من سلامة الملف

يمكن مقارنة بصمة SHA-256 التالية مع بصمة الملف الذي تم تنزيله:

```
4fa1d1344612e9520398acece4284744788cb075e1d722d4334814ee594cdf8d
```

في Windows يمكن حساب البصمة باستخدام الأمر التالي من موجه الأوامر أو PowerShell:

```
Get-FileHash ".\CryptoLab.Setup.1.1.0.win-x64.exe" -Algorithm SHA256
```

ينبغي أن تتطابق قيمة `Hash` الناتجة مع البصمة الموضحة أعلاه.

## ملاحظة المعمارية

هذه النسخة مخصصة لأجهزة Windows ذات معمارية `x64`، وهي المعمارية الشائعة لمعظم أجهزة Windows الحديثة. لا ينبغي تثبيت نسخة `win-x64` على أجهزة Windows 32-bit أو ARM64؛ إذ يلزم إنشاء حزمة منفصلة بالمعمارية المناسبة لتلك الأجهزة.

## النسخة المحمولة

توجد نسخة نشر غير مضغوطة ضمن مجلد البناء المحلي:

```
publish/CryptoLab-win-x64
```

يمكن استخدام هذه النسخة المحمولة بتشغيل `CryptoLab.exe` مباشرة، بشرط إبقاء جميع الملفات الموجودة داخل المجلد معاً. حذف أي ملف من مجلد النشر قد يمنع التطبيق من العمل.

> النسخة المحمولة ليست هي المثبت التنفيذي، ولا ينبغي نقل الملف التنفيذي وحده من مجلد النشر. أما الملف المتاح للتنزيل العام فهو مثبت Windows الموجود ضمن إصدار GitHub.

## نتيجة الاختبار

نجح بناء النشر الذاتي باستخدام `dotnet publish`، كما نجح بناء مُثبّت Inno Setup. ونجح التثبيت الصامت برمز خروج `0`، ثم تم العثور على `CryptoLab.exe` وتشغيله بنجاح لمدة اختبارية قصيرة بعد التثبيت.

تم رفع المثبت التنفيذي إلى GitHub كأصل Release مستقل، بينما بقيت ملفات البناء الكبيرة والمخرجات المولدة خارج شجرة المصدر الأساسية للمستودع.
